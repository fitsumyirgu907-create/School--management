🧩 Smart School Tools

👤 Automatic Account Creator

Create Student, Teacher or Parent login accounts from one place. A temporary password can be issued for first login.

🔐 Registrar Role & Permissions

Registrar access is separated from Owner/Admin access. It can manage student/teacher records and account creation without receiving full system control.

Registrar role is available in this version. Database RLS must also enforce the same permissions.

💬 Parent ↔ Teacher Messaging

Send an in-app message between a parent and a teacher. Messages are stored in the messages table.

💡 Parent Feedback / Suggestion

Parents can submit feedback or suggestions. Admin/Director can review them.

🔔 Automatic Absence Notification

When attendance is saved as Absent, the system creates an in-app notification for the linked parent.

📡 Offline Mode + Internet Sync

The app keeps a local snapshot and a small pending queue while offline, then can synchronize queued records when internet returns.

🗄️ Backup / Restore

Download a JSON backup of the data currently loaded in this browser. Restore adds/upserts records; it does not intentionally delete existing records.

👑 Admin User Edit / Delete

Admin/Owner can edit the profile fields in users. Authentication email/password changes still require the secure Edge Function.

📊 Excel Data Center

Download school data to Excel for backup/reporting, or upload an Excel file to add records. Existing database records are not automatically deleted by import.
